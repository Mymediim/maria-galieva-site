# Личный сайт Марии Галиевой

Статический Astro-сайт продуктового консультанта и основателя IT Production. Исходный утверждённый прототип сохранён в `prototype-desktop.html`.

## Локальная работа

```powershell
npm install
npm run dev
npm run build
npm run preview
```

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните только нужные значения:

- `PUBLIC_YANDEX_METRIKA_ID` — числовой идентификатор Яндекс Метрики;
- `PUBLIC_GA_ID` — идентификатор Google Analytics вида `G-...`;
- `PUBLIC_SITE_URL` — финальный адрес сайта с `https://`, без завершающего `/`;
- `PUBLIC_SITE_INDEXING=true` — включать только после подключения домена и финальной проверки.

Аналитика загружается только после согласия посетителя. До включения `PUBLIC_SITE_INDEXING` страницы содержат `noindex`, а `robots.txt` запрещает индексацию.

## Страницы

- `/` — лендинг;
- `/privacy/` — политика обработки персональных данных;
- `/agreement/` — пользовательское соглашение.

## Проверка перед публикацией

```powershell
npm run build
```

До указания домена и финальной юридической проверки сборка остаётся закрытой от индексации.
