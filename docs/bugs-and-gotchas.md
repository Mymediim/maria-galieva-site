### 2026-09-18 — Приватный репозиторий отключает GitHub Pages

- Симптом: домен начинает отдавать 404, HTTPS перестаёт работать, а API GitHub Pages возвращает 404.
- Причина: репозиторий сайта был переведён из public в private; для текущего тарифа публикация GitHub Pages была удалена вместе с привязкой домена.
- Решение: вернуть репозиторию видимость public, заново включить Pages с типом сборки `workflow`, привязать `maria-galieva.ru`, запустить deploy и после выпуска сертификата включить обязательный HTTPS.
- Проверка: workflow завершён успешно; `https://maria-galieva.ru/` отдаёт 200, `https://www.maria-galieva.ru/` перенаправляет на основной домен.
- Где связано: GitHub repository settings, `.github/workflows/deploy.yml`, DNS домена в Timeweb.
