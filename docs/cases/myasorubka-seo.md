# «Мясорубка»: SEO-настройки кейса

Подготовлено 21 октября 2026 года. Мария подтвердила commit, отправку в GitHub и публикацию с открытой индексацией. Тексты проекта и рассказ Марии — источник фактов о решении, а не сайты конкурентов.

- Адрес: `/cases/avtomatizaciya-rabochego-mesta-myasnika/`.
- Title: «Рабочее место мясника: автоматизация учёта | Мария Галиева».
- Description: «Автоматизация мясных магазинов на примере сети „Мясорубка“: учёт разруба, актуальные остатки в CRM и контроль отклонений. Продуктовый кейс Марии Галиевой».
- Основная тема: автоматизация рабочего места мясника, рабочее место мясника.
- Смежные задачи: автоматизация мясных магазинов и сети магазинов, складской учёт, отрицательные остатки в CRM, учёт разруба, контроль выхода продукции и потерь.
- Воровство раскрывается как поиск расхождений для проверки. Доказанного снижения числа краж нет; расхождение само по себе не доказывает кражу.
- Одна страница под связанный набор задач; не создаём дубли под варианты ключевых слов.
- Заголовок H1 сохранён; тематическое уточнение в надзаголовке и видимом блоке вопросов руководителей.
- Canonical, Article, BreadcrumbList, Open Graph и Twitter используют основной домен из конфигурации.
- В production sitemap входят главная и кейс; закрытая сборка запрещает индексацию обеих страниц.
- Кейс подключает существующий компонент согласия на аналитику.

## Основания и ограничения

Открытая выдача 21.10.2026 по «автоматизация мясных магазинов» показывает решения для учёта, разделки и управления розницей. Это качественный ориентир намерения пользователя, а не измерение частотности. Данные Wordstat, Search Console и Вебмастера в этой задаче не получены. Позиции и сроки выхода в поиск не обещаются.

Рекомендации Google: [содержательные заголовки страниц](https://developers.google.com/search/docs/appearance/title-link), [Article](https://developers.google.com/search/docs/appearance/structured-data/article). FAQ размещён для читателя, без обещания специального FAQ-сниппета.

## Проверка выпуска

`npm run check`, `npm run build`, `npm run verify:seo:open` при `PUBLIC_SITE_URL=https://maria-galieva.ru` и `PUBLIC_SITE_INDEXING=true`; затем закрытая сборка и `verify:seo:closed`. После публикации — `npm run verify:production` и проверка ссылки с главной. Запрос переобхода в поисковых кабинетах — отдельное действие после выпуска.
