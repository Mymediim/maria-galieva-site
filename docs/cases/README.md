# Кейсы личного сайта Марии Галиевой

Здесь хранятся персональные версии кейсов для сайта продуктового консультанта.
Они показывают личную роль Марии, ход анализа и логику решений и не заменяют
портфолио команды IT Production.

## Правила подготовки

1. До написания определить канонический fact sheet проекта и дату его версии.
2. Отдельно зафиксировать подтверждённые действия Марии и работу команды.
3. Использовать `я` только для личных действий Марии. Дизайн, разработку,
   тестирование и выпуск приписывать исполнителю, который их выполнял.
4. Строить рассказ вокруг решения собственника до или во время разработки:
   ситуация → вопросы → варианты → выбор → реализация командой → результат.
5. Не копировать блоки с сайта IT Production и не переносить командные
   рекламные формулировки.
6. Не добавлять продажи, ROI, проценты экономии и рыночный спрос без
   подтверждённых данных.
7. Завершать кейс приглашением на бесплатную диагностическую встречу по
   похожей задаче.

## Рабочая метка

В задачах и черновиках используется метка `[Мария — консалтинг]`. Для
материалов сайта компании применяется отдельная метка `[IT Production]`.
