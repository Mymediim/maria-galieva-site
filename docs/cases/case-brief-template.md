# Бриф следующего кейса

Копировать для конкретного проекта. Неизвестное отмечать «нужно уточнить», не заполнять предположениями. Порядок работы: [case-workflow.md](case-workflow.md).

- Для кого кейс и какую похожую задачу он помогает узнать:

- Hero: не больше 4 смысловых групп; что сохраняется в H1 при сокращении и как кадрируется изображение без искусственных полос:
