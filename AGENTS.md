# Правила сайта Марии Галиевой

## Назначение и границы

- Это самостоятельный статический Astro-проект личного сайта Марии Галиевой, продуктового консультанта и основателя IT Production.
- Текущая папка проекта: `IT Production/Консалтинг`. Планируемый будущий корень — `IT Production/Сайт Марии Галиевой`; до отдельного подтверждённого переноса ничего не перемещать и не архивировать.
- Не использовать фирменный стиль IT Production автоматически: применяй только утверждённые материалы этого проекта или прямой запрос Марии.

## Публикация и данные

- Не публиковать и не включать индексацию без отдельного подтверждения Марии.
- Не записывать реальные доступы в Markdown, исходный код или Git. `.env` остаётся локальным, а его значения никогда не выводятся.
- Не приписывать Марии опыт, клиентов, результаты, цифры, отзывы или юридические утверждения без подтверждённого источника и разрешения на публикацию.

## Техническая работа

- Перед изменением читать `README.md`, `docs/README.md` и `docs/project-memory.md`.
- `prototype-desktop.html` и `desktop-design.css` участвуют в текущей сборке; не перемещать их без корректировки импортов и проверки `npm run build`.
- Сохранять Git-историю, не удалять ветки и не переписывать существующие изменения без отдельного разрешения.
- Перед публикацией или существенным изменением выполнить соразмерную проверку: `npm run check`, `npm run build` и визуальную проверку затронутых страниц.

## Память проекта

- Долговечные решения записывать в `docs/decision-log.md`.
- Повторяющиеся подтверждённые ошибки и обходные пути записывать в `docs/bugs-and-gotchas.md`.
- Не превращать журналы в перечень всех мелких правок и не дублировать в них исходные материалы или секреты.

## Локальная Git-работа

- Русский словарь команд находится в `docs/local-git-workflow.md`.
- Фразы «сохрани точку», «зафиксируй изменения» и «сделай снимок проекта» означают: показать `git status`, назвать изменённые файлы, проверить, что среди них нет секретов и временных данных, затем создать локальный commit только после согласования Марии.
- Фразы «что изменилось?» и «покажи diff» означают: выполнить `git status` и `git diff`, затем объяснить результат кратко по-русски.
- Фраза «покажи историю» означает: выполнить `git log --oneline --max-count=10`.
- Откатывать можно только конкретный файл и только после показа теряемых изменений и подтверждения Марии. Не выполнять `git push` без прямого запроса.
